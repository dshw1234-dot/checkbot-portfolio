# 개발 구조

MS To Do 재현 앱. PC는 Tauri(WebView2), 아이폰은 PWA로 같은 웹 코드를 쓴다.
소스는 비공개 저장소 `dshw1234-dot/todo-app-src`(origin)에 올린다. 아이폰용 빌드 결과만 공개 저장소 `dshw1234-dot/todo-app`(GitHub Pages, `npm run deploy`)에 간다.
기능 기준은 `docs/명세/기능_명세서.md`(원본 기준선)와 `docs/명세/모바일_명세서.md`, 기술 기준은 같은 폴더 `기술_결정_메모.md`.

## 데이터

- 모든 레코드: `id`(UUID, 기본 목록 '작업'만 `inbox`), `_t`(필드별 수정 시각), `deleted`(묘비), `deviceId`.
- 표: `lists`, `groups`, `tasks`, `steps`, `files`(메타), `blobs`(파일 내용, 기기 안에만), `settings`, `outbox`, `meta`.
- 반복 규칙은 문자열: `day/n`, `weekday/1`, `week/n/0.2.4`(0=일), `month/n/일`, `year/n`.
- 오늘 할 일: `myDay`(추가한 날짜), `myDayOrder`(오늘 할 일 안의 순서), `myDayOff`(오늘 기한이라 자동으로 들어온 걸 뺀 날).

## 추가 기능 넣는 법

1. `src/features/<이름>/index.jsx`를 만들고 `register('<이름>', { 끼움 자리 })`.
2. `src/features/index.js`에 `import './<이름>/index.jsx';` 한 줄.
3. 끼움 자리: `taskMenu`, `rowMeta`, `detailCards`, `smartLists`, `settings`, `listMenu`(좁은 화면 목록 ⋯), `addSheet`(좁은 화면 입력 시트 위), `fileRows`(세부 정보 파일 칸 '파일 추가' 아래), `stepRows`·`stepMenu`(단계 줄 아래·단계 ⋮ 메뉴) (자세한 형식은 `src/features/registry.js`). `smartLists`(2026-10-24 연결)는 `{ key, label, icon, filter, groups? }`를 돌려주면 왼쪽 메뉴 '모두' 다음에 스마트 목록으로 보이고(`App.jsx` `metaOf`, `Sidebar.jsx`, `ListPane.jsx` `Body`, 묶기 `core/views.js` `featureGroups`), 작업 추가 칸·정렬·끌어다 놓기는 없다. 기능 스타일은 기능 폴더의 css 를 `index.jsx` 에서 import.
4. 새 필드가 필요하면 그냥 레코드에 넣는다(repo 가 모르는 필드도 보존·동기화).
5. 원본 동작을 바꾸는 기능이면 `docs/명세/추가_기능.md`에 원본 ID와 함께 적는다.

원본 재현 완료 시점은 git 태그 `v1-원본재현`(2026-10-24, 커밋 9278bdb, MS To Do 데이터 옮기기까지 포함)으로 남겼다. 그 뒤로 `git diff v1-원본재현`이 곧 "내가 바꾼 것".

## 명령

```
npm run dev     # http://localhost:5199
npm test        # 단위 테스트(vitest)
npm run check   # 끝났다고 말하기 전 한 번에: BOM·JSON → eslint → vitest → 화면 검사(Playwright) → 빌드. check:fast 는 앞 셋만(커밋 훅)
npm run test:ui # 화면 검사만(npx playwright test -g "이름" 으로 하나만)
npm run lint    # eslint 만
npm run build   # dist/ (PWA 배포물, Tauri가 감쌀 웹 파일)
npm run sync    # 비공개 저장소와 맞추기: 받기(rebase) → 올리기, 안 합친 클라우드 가지 표시
npm run deploy  # 빌드 → GitHub Pages 올리기 → 공개 주소 판 번호 확인(미커밋 변경 있으면 멈춤, --force / --check [--wait 초] / --no-wait)
npm run ship    # 커밋 뒤 한 번에: check → sync → pc(앱 파일이 바뀐 때만) → 폰 배포(GitHub Actions 가 켜져 있으면 기다리기만). --no-pc / --no-deploy
node scripts/server-check.mjs [--login | --compare 진단.json]   # 서버 records 요약, 기기 진단과 대조(로그인 토큰은 %APPDATA% 에)
```
