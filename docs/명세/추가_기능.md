# 추가 기능: 원본 재현 기준선 위에 사용자가 고른 기능

- 원본 재현 기준선(`기능_명세서.md`, `모바일_명세서.md`, 태그 `v1-원본재현`)은 고치지 않고, 사용자 취향으로 더하거나 바꾼 기능을 여기 쌓는다.
- 칸: **ID** / **이름**(`용어집.md`의 부를 이름) / **원본 ID**(관련 명세 항목) / **동작** / **코드**.
- 코드는 `src/features/<이름>/`에 넣고 `src/features/registry.js`의 끼움 자리로 화면에 붙인다(`개발_구조.md` "추가 기능 넣는 법").
