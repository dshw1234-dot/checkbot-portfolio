# 용어집: 체크봇의 화면·기능·버튼 이름

- 목적: 사용자와 Claude(로컬·클라우드 세션 모두)가 같은 것을 같은 이름으로 부르게 한다. 기능을 요청하거나 고칠 때는 **부를 이름**을 쓴다.
- 칸: **부를 이름**(대화·문서에서 쓰는 말) / **화면 문구**(앱에 실제로 보이는 글, MS To Do 원문을 따름) / **ID**(`기능_명세서.md`·`모바일_명세서.md`의 항목) / **코드**(필드·파일 이름).
- 부를 이름과 화면 문구가 다른 것은 화면 문구를 MS To Do 그대로 두었기 때문이다. 화면 문구를 바꾸고 싶으면 `추가_기능.md`에 적는다.
- 새 기능을 넣으면 여기에 이름을 먼저 정해 적는다.
- 2026-10-27 이름 바꾸기 전 문서(설계 문서·실수 기록 등)에는 옛 이름이 남아 있다: 할 일 = 작업, 목록 = 리스트, 할 일 앱 = 체크봇, 할 일 통로 = PC 통로, 할 일 스킬 = 체크봇 스킬, 커넥터 '할 일' = 커넥터 '체크봇'.
