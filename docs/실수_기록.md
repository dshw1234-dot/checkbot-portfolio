# 실수 기록과 자기 검사 장치

Claude 가 이 앱을 만들며 저지른 실수를 갈래별로 모으고, 같은 실수를 **사람이 아니라 검사가 먼저 잡게** 만든 장치를 적는다.
새 실수가 나면 여기에 한 줄 더하고, 되도록 회귀 테스트와 함께 남긴다. (2026-10-24 세션 기록 7개, 약 90건 조사에서 시작)

## 다섯 관문

```
코드 고침 ─▶ npm run check ─▶ 커밋(훅) ─▶ 배포(판 확인) ─▶ 실기·서버 대조
             BOM·lint·테스트     check:fast     미커밋 중단       설정→진단
             화면·빌드           안 돌면 막힘    version.json      server-check
```

| 관문 | 명령 | 잡는 것 |
|---|---|---|
| 1. 전체 검증 | `npm run check` (약 30초) | BOM·깨진 JSON, hooks 규칙 위반, 단위 테스트, 화면 흐름(PC 폭·375px, 콘솔 오류 0), 빌드 |
| 2. 커밋 훅 | `.githooks/pre-commit` → `npm run check:fast` (약 10초) | 1의 앞 세 단계를 안 돌리고 커밋하는 것. `sync.mjs --start` 가 연결. 급하면 `--no-verify`, 그 뒤 반드시 `npm run check` |
| 3. 배포 검사 | `npm run deploy` | 커밋 안 한 변경이 섞여 올라가는 것(멈춤, `--force` 로 지나감), 공개 주소가 새 판을 내보내는지(`version.json` 의 commit 이 HEAD 와 같아질 때까지 기다림, `--check` 로 따로) |
| 4. 진단·대조 | 앱 설정 → 진단(복사·내보내기), `window.__todoDiag()`, `node scripts/server-check.mjs [--compare 진단.json]` | 기기마다 개수가 다른 것, 올리지 못한 변경, 옛 판으로 도는 기기, 서버에만·기기에만 있는 id |
| 5. 규칙 | `CLAUDE.md` "끝났다고 말하기 전에" | 확인 안 한 것을 확인했다고 말하는 것, 실데이터 실험, 셸로 파일 쓰기 |

### 4. 빌드·배포 판 불일치(8건)

- 2026-10-25 아이폰·PC claude.ai 에서 "할 일에 있는 …"이라고 하면 Claude 가 '할 일' 커넥터 대신 Chrome 으로 Microsoft To Do(`to-do.live.com`)를 찾음(아주 잦음). 원인 둘: ① 함수가 MCP SDK v1(1.25.3)이라 Claude 가 먼저 보내는 새 규약(2026-07-28) 요청을 매번 400 으로 거절했고, Claude 가 옛 규약으로 다시 붙지 않은 대화에는 '할 일' 도구가 없었다(함수 로그에 400 하나만 오고 끝난 것이 하루 3번 이상) ② claude.ai 메모리 'Task Management'(2026-10-22)에 "Microsoft To Do 사용, 크롬으로 To Do 웹 조작을 맡길 예정"이 남아 있어, 서버를 고친 뒤에도 Claude 가 그 메모리를 읽고 Chrome 으로 감. 고침: SDK v2(`@modelcontextprotocol/server` 2.4.0, 새·옛 규약 둘 다) 함수 판 4(`bd5589d`), 메모리 내용을 '할 일' 커넥터로 바꿈 → Edge·아이폰(사용자 확인) 새 대화에서 '할 일 찾기 사용함', 로그 400 없음. **장치:** `tests/agent-remote-protocol.test.js`(새 규약 `server/discover`·`tools/list`·`tools/call` 이 200, 옛 규약 initialize 도 200, `index.ts`·`package.json`·`mcp.js` 의 SDK 판이 같고 v1 이 아님). 커넥터가 안 쓰이면 함수 로그에서 "400 하나만"과 claude.ai 메모리를 먼저 본다(`docs/설정_안내.md` 5-3 "아이폰에서 연결할 때").
- 2026-10-25 할 일 스킬 설치 시험: 스킬 글대로 Bash 도구에서 `node C:\Users\…\todo.mjs` 를 부르자 Bash가 역슬래시를 지워 "Cannot find module". **장치:** `skills/todo-agent/references/설정.md` '통로 호출' 칸에 슬래시 경로를 적고 SKILL.md가 그것만 쓰게 함(허용 목록 `Bash(node *tools/todo-agent/todo.mjs *)`도 슬래시에만 맞음).

### 7. 세션 사이 전달·충돌(6건)
